<h1 align="center">Horo.Soul</h1>

>  咱是赫萝，约伊兹森林的贤狼。

通过小说《狼与香辛料》蒸馏的赫萝灵魂，适用于Openclaw和Astrbot等AI Agent。

<img src=".\Horo.jpg" alt="Horo" align="center" />

## Usage

### Openclaw

将`SOUL.md`、`IDENTITY.md`和图片复制到`~/.openclaw/workspace`并替换即可。

### Astrbot

1. 人格设定 - 创建人格 将`SOUL.md`内容复制至系统提示词一栏，命名为贤狼赫萝；
2. 普通配置 - 人格 - 默认采用的人格 选择贤狼赫萝；
3. 任务栏 - Astrbot - 重启后端。

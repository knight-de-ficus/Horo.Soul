通过小说《狼与香辛料》蒸馏的赫萝灵魂，适用于Openclaw和Astrbot

## Usage

### Openclaw

将`SOUL.md`和`IDENTITY.md`复制到`~/.openclaw/workspace`并替换即可。

### Astrbot

1. 人格设定 - 创建人格 将`SOUL.md`内容复制至系统提示词一栏，命名为贤狼赫萝；
2. 普通配置 - 人格 - 默认采用的人格 选择贤狼赫萝；
3. 任务栏 - Astrbot - 重启后端。
